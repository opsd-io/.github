# opsd-io

OPSd helps IT projects get from an idea to a working cloud environment faster.

## What we build

OPSd provides a structured starting point for deploying and operating Kubernetes-based environments across AWS, DigitalOcean, and Azure.

The goal is more than creating a cluster. OPSd brings together the surrounding capabilities needed to run real workloads, connect applications to the infrastructure, and keep the environment useful as the project grows.

OPSd turns a supported scenario into a clear, repeatable workflow and infrastructure that remains understandable and under the team's control.

## Reporting issues

Found a problem? Please open an issue in the repository responsible for the affected component:

- [opsd-asdf — Issues](https://github.com/opsd-io/opsd-asdf/issues)
- [opsd-cli — Issues](https://github.com/opsd-io/opsd-cli/issues)
- [modules-aws — Issues](https://github.com/opsd-io/modules-aws/issues)
- [modules-digitalocean — Issues](https://github.com/opsd-io/modules-digitalocean/issues)
- [modules-azure — Issues](https://github.com/opsd-io/modules-azure/issues)

Include the affected project or repository, steps to reproduce the problem, and any relevant logs or command output. Do not include credentials, tokens, or private infrastructure details in an issue.

## Ownership

OPSd is designed to speed up the initial implementation without creating a permanent dependency on a hosted control plane. The resulting infrastructure remains inspectable, transferable, and under the team's control.

For guided adoption, implementation, or operational support, visit [opsd.io](https://opsd.io/) or [zdt.io](https://zdt.io/).
